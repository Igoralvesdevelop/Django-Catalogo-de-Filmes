# 🎬 Catálogo de Filmes - Projeto Django

Este é um projeto Django simples para cadastro e listagem de filmes. Cada filme possui título, ano, capa e descrição, e a interface exibe os filmes em cards clicáveis que revelam mais detalhes.

---

## 🚀 Requisitos

- Python 3.10+ (recomendado: 3.11+)
- pip (gerenciador de pacotes do Python)
- Ambi
